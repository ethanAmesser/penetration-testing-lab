# Penetration Testing & Vulnerability Assessment Lab

## Overview
This project documents a black-box penetration test conducted on a Linux-based server environment. The objective was to identify vulnerabilities that could impact the confidentiality, integrity, and availability of the system.

## Tools Used
- Kali Linux
- Nmap
- Netcat
- Linux command-line tools

## Skills Demonstrated
- Network enumeration
- Service and version scanning
- Vulnerability discovery
- Privilege escalation
- Security risk analysis

## Key Activities
- Performed network enumeration to identify reachable hosts and network configuration.
- Conducted Nmap service and version scans to identify running services such as SSH, Apache, and MariaDB.
- Identified vulnerabilities including anonymous FTP access and misconfigured sudo permissions.
- Demonstrated root privilege escalation and documented mitigation strategies to improve system security.
